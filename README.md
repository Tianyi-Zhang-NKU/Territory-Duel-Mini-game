## 📝 v2.0 更新日志 (Changelog)

本次更新集中于**核心交互逻辑的实装**与**代码工程质量的优化**，实现了从静态界面到动态塔防玩法的跨越。

### 1. 🎮 核心玩法与交互 (Gameplay & Interaction)

- **拖拽放置系统 (Drag-and-Drop Deployment)**：
  - 完整实现了“商店购买 -> 鼠标拖拽 -> 网格种植”的交互闭环。
  - 利用 Qt 事件处理机制 (`QMouseEvent`, `QDrag`)，实现了武器卡片的拾取与放置逻辑。
- **武器系统实装**：
  - **加农炮 I / 加农炮 III / 滚轮**：三种核心单位现在可以被正确实例化并部署在游戏地图上，且具备独立的功能逻辑。
  - 解决了放置时的边界检测与重叠检测问题。

### 2. 🧹 代码重构与工程化 (Refactoring & Engineering)

- **代码规范化**：
  - **命名约定 (Naming Convention)**：全面统一了变量与函数的命名风格（如采用驼峰命名法），消除了歧义。
  - **注释增强**：系统化地补充了核心算法与类接口的注释（Comments），显著提升了代码的可读性与可维护性。
- **模块解耦**：优化了现有代码结构，为后续扩展新敌方单位预留了清晰的接口。

### 3. ⚖️ 场景搭建与平衡 (Scene & Balance)

- **战斗场景整合**：完成了游戏主场景（Game Scene）的完整搭建，实现了 UI 层与游戏逻辑层的无缝融合。
- **参数调优**：初步调整了武器费用、冷却时间及初始资源等核心参数，优化了游戏初期的节奏体验。

## 🗺️ v3.0 开发规划 (Roadmap)

下一阶段将重点丰富游戏内容的多样性，并打磨视觉表现：

- **视觉与反馈优化 (Visual Polish)**：
  - 进一步提升游戏视图的渲染效果，优化动画流畅度。
-  **敌方单位扩展 (Enemy Expansion)**：
  - **敌方战机 (Enemy Jet)**：实现空中单位的移动路径规划与攻击逻辑。
  - **云朵 (Cloud)**：实现障碍物/环境单位的属性与交互效果。
