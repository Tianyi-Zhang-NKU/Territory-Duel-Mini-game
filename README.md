## 📖 项目简介

本项目是一款基于 Qt 框架开发的 2D 策略塔防类游戏。玩家需要通过策略性地部署武器单位，收集资源（阳光），并在限定时间内抵御敌方目标的进攻以取得胜利。

## 📝 版本更新日志 (Changelog)

### 🚀 v1.0 Alpha 

**当前版本核心功能实现情况：**

#### 1. 🎨 美术与资产 (Assets & UI)

- **AIGC 资产生成**：利用 AI 工具辅助生成了项目所需的全套美术素材（包括单位、背景、UI 组件）。
- **界面系统**：完成了游戏三大核心界面的搭建与路由跳转：
  - `StartScene` (开始界面)
  - `GameScene` (主游戏界面)
  - `GameOverScene` (结算界面：包含胜利/失败状态)

#### 2. ⚔️ 单位与战斗系统 (Combat System)

- **己方单位**：初步实装了三种核心武器，具备不同的攻击逻辑：
  - **加农炮 I型 (Cannon I)**
  - **加农炮 III型 (Cannon III)**
  - **滚轮 (Roller)**
  - *(注：原定“己方飞机”与“加农炮 IV”根据设计迭代已移除，聚焦核心玩法)*
- **弹道机制**：实现了子弹对象 (`Bullet`) 的实例化，并完成了与不同类型加农炮的发射逻辑绑定。
- **敌方单位**：实现了基础敌方单位“方块对象”，并建立了基本的碰撞检测机制（Collision Detection）：
  - 当敌方与我方子弹或滚轮接触时，触发销毁逻辑。

#### 3. 💰 经济与资源系统 (Economy System)

- **资源产出**：实现了类似 PVZ 的“阳光”随机掉落算法。
- **交互反馈**：实现了鼠标点击拾取阳光并增加资源计数的功能。
- **商店模块**：完成了卡片槽（Card Slot）与商店 UI 的绘制与基础逻辑。

#### 4. ⚙️ 核心游戏循环 (Game Loop)

- **胜负判定机制**：
  - **胜利条件**：在倒计时结束前，将敌方单位数量削减至特定阈值。
  - **失败条件**：超过规定时间未能达成清除目标。

## 🗺️ 开发路线图 (Roadmap v2.0)

下一版本将重点攻克交互体验与游戏平衡性，计划包含以下内容：

- **交互逻辑重构 (Interaction)**：
  - 参考《植物大战僵尸》机制，实现**卡片拖拽 (Drag & Drop)** 放置武器的功能（*v2.0 核心目标*）。
-  **视觉体验优化 (Visuals)**：
  - 对现有的游戏视图进行渲染优化，提升 UI 精致度。
-  **数值平衡 (Balancing)**：
  - 在场景搭建完毕的基础上，调整武器伤害、冷却时间及敌方血量等核心参数。
-  **敌方AI增强 (Enemy AI)**：
  - 详细规划并实装“敌方战机”与“云朵”对象的属性与行为逻辑。
