## 📖 项目简介 (Project Overview)

本项目是一款基于 Qt 框架开发的 **2D 策略塔防类游戏**。

游戏核心玩法借鉴了经典塔防机制，玩家需要通过策略性地部署不同功能的武器单位，收集动态资源（阳光），并在倒计时结束前抵御敌方目标的进攻。项目实现了完整的游戏循环，包含资源管理、即时战斗、胜负判定及多场景切换。

## 🛠️ 技术特性与实现细节 (Technical Details)

### 1. 核心架构 (Architecture)
* **面向对象设计 (OOP)**：
    * 采用继承多态管理游戏单位。基类定义通用属性（如坐标、血量），派生类实现特定行为（如不同加农炮的攻击频率、移动方式）。
* **场景管理**：
    * 基于 Qt 的信号与槽机制 (Signals & Slots) 实现场景间的无缝切换与数据传递。

### 2. 交互逻辑 (Interaction Logic)
* **事件处理**：
    * 重写 `mousePressEvent`, `mouseMoveEvent`, `mouseReleaseEvent` 实现拖拽种植。
    * 通过坐标映射算法，将屏幕像素坐标转换为游戏地图的网格索引 $(row, col)$，确保单位放置的整齐划一。

### 3. 资源与算法 (Assets & Algorithms)
* **资源生成**：采用随机算法控制阳光掉落的频率与位置。
* **碰撞检测**：基于矩形包围盒 (AABB) 判定子弹与敌人的接触，触发伤害计算与对象销毁。
